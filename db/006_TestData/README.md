# Test Data

This folder is reserved for fictional local test data scripts.

Do not place production data, real user information, real emails, real company names, or secrets here.

Development demo users are created at runtime when `LeaveFlow:Development:BootstrapIdentity` is true. Supply passwords through user secrets or environment variables. Do not commit those passwords.
